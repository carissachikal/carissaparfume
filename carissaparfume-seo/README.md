# CARFUME — Your Signature Scent

Website resmi **Carfume** — parfum aesthetic berbasis di Kalideres, Jakarta Barat.

**Live:** https://carfume.my.id/

## Fitur SEO yang sudah ditambahkan

- `robots.txt` — mengizinkan semua crawler + pointer ke sitemap
- `sitemap.xml` — daftar halaman utama
- Meta tags lengkap (title, description, keywords, robots, geo)
- Open Graph & Twitter Card tags
- Canonical URL
- Structured Data (JSON-LD) untuk Store & Product
- Favicon SVG (sudah ada)
- `og-image.jpg` (1200×630) untuk share di sosial media
- `site.webmanifest` untuk mobile / PWA-like

## Cara deploy (GitHub Pages / static hosting)

1. Upload semua file di folder ini ke root repo GitHub Pages-mu (atau ganti file yang sudah ada).
2. Pastikan `CNAME` berisi `carfume.my.id` jika pakai custom domain.
3. Setelah deploy, verifikasi:
   - https://carfume.my.id/robots.txt
   - https://carfume.my.id/sitemap.xml
   - https://carfume.my.id/og-image.jpg

## Langkah SEO selanjutnya (manual)

Lihat file `SEO-GUIDE.md` di dalam ZIP ini untuk panduan lengkap step-by-step.
