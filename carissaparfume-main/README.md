## Auto-scroll
Website sekarang memiliki auto-scroll: setelah 2 detik tanpa aktivitas, halaman akan bergerak perlahan ke bawah. Saat user berinteraksi, auto-scroll berhenti dan akan aktif kembali 2 detik setelah user diam. Ketika sampai bagian paling bawah, halaman kembali cepat ke paling atas lalu melanjutkan auto-scroll ke bawah.
