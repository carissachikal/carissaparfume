# CARFUME — Your Signature Scent

Website resmi **Carfume** — parfum aesthetic berbasis di Kalideres, Jakarta Barat.

**Live:** https://carfume.my.id/

## Yang sudah dioptimasi

### SEO
- Meta tags lengkap (title, description, keywords, geo)
- Open Graph + Twitter Card
- Canonical URL
- Structured Data (JSON-LD Store + Product)
- `robots.txt` + `sitemap.xml`
- `og-image.jpg` (1200×630)
- `site.webmanifest`

### Accessibility (PageSpeed Accessibility target 95+)
- Label untuk `<select>` sorting
- `aria-label` pada semua tombol ikon
- Contrast ratio ditingkatkan (teks muted lebih gelap)
- Screen-reader utility class `.sr-only`
- Role & group pada filter buttons

### Visual & UX
- Warna lebih kaya & kontras lebih baik
- Hover effect produk lebih halus
- Tombol & filter lebih jelas
- Mobile responsive tetap rapi

### Performance
- Sudah 99 di PageSpeed (Desktop)
- Gambar tetap lazy-load
- Font Google preconnect

## Deploy

1. Upload semua file di folder ini ke root repo GitHub Pages.
2. Pastikan `CNAME` = `carfume.my.id`.
3. Verifikasi:
   - https://carfume.my.id/robots.txt
   - https://carfume.my.id/sitemap.xml
   - https://carfume.my.id/og-image.jpg

## Langkah SEO lanjutan

Baca **SEO-GUIDE.md** untuk panduan Google Search Console, Google Business Profile, dll.
